# 미래 출발의 따릉이 재고

재고 기준시각부터 대여 예정시각까지 60분을 넘는 경우에도 따릉이와 혼합 경로를 탐색합니다. 재고 예측 범위를 늘리지는 않습니다.

해당 자전거 구간에는 `details.inventory_status = "outside_60min_horizon"`, `p_empty = null`을 유지합니다. 웹은 경로 카드와 해당 구간에 재고 미확인 및 이용 전 재확인 안내를 표시합니다. 이 경로가 반환돼도 자전거 확보가 보장되지는 않습니다. 실시간 자동 재확인은 이번 변경에 포함되지 않습니다.

60분 이내의 재고 위험 임계값, 오래된 재고 관측 및 지원하지 않는 대여소의 제외 조건은 유지합니다. 미래 재고 예측을 연쇄 적용하거나 현재 재고를 미래 재고로 간주하지 않습니다.
