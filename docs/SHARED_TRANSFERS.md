# 공유 환승 자료

Git에서 받은 코드로 웹 서버를 실행하면 개선된 통합 탐색과 공유 환승 자료가 함께 적용됩니다. 다른 사람이 이미 실행 중인 사이트에 접속할 때는 해당 서버의 코드·캐시를 사용합니다.

`data/reference/walking_transfers.sqlite.gz`에는 공개 시설 사이의 카카오 확인값 919건, OSM 계산값 37,554건과 보행망이 들어 있습니다. 압축 파일은 약 70MB입니다. 첫 검색 때 해당 PC의 실행 캐시로 자동 해제하며, 보행망이 없는 PC에서는 포함된 보행망을 사용합니다. Overpass 재수집이나 기존 PC의 `bicycle_local` 복사가 필요하지 않습니다.

- 개인 출발지·목적지, 계정, 비밀번호, API 키, 개인 이용이력, 재고 관측, 날씨, API 사용량은 공유하지 않습니다.
- 시설 번호와 좌표가 맞는 구간만 사용합니다. 이동하거나 폐쇄된 시설에 예전 좌표의 경로를 붙이지 않습니다.
- 현재 PC에서 새로 확인한 카카오 결과가 우선합니다. 공유 카카오 값도 최초 조회시각으로부터 7일이 지나면 사용하지 않습니다.
- OSM 값은 도로망 내용이 동일할 때만 재사용하고, 현재의 카카오 확인 필요 조건을 다시 검사합니다. 도로망이 바뀌거나 확인이 필요한 구간은 기존 도보 계산·API 조회 절차로 처리합니다.
- 과거 검색의 도착시각을 재사용하지 않습니다. 시간표, 이동시간 모델, 출발시각과 도착시점의 재고 판단은 현재 검색에 맞춰 적용합니다.

다른 PC에서는 `git pull` 후 서버를 재시작합니다. 처음 설치하는 PC는 README의 설치 절차를 진행하고, 자신의 API 인증키를 `.env`에 설정합니다. 개인화 DB와 새로 생성되는 캐시는 PC별로 관리합니다.

자료 식별값·크기·건수는 `walking_transfers.json`에 기록했습니다. 갱신 스크립트는 `scripts/export_walking_transfers.py`이며 공개 시설 좌표 JSON과 로컬 도보 캐시를 입력받습니다. 원본 API 응답 대신 허용된 도보 정보만 내보내며, 조회일을 갱신일로 바꾸지 않습니다.
