# 시설 좌표 점검

자료 확인일: 2026-10-30. 코드 반영일: 2026-11-01.

## 확인 범위

| 구분 | 비교한 자료 | 결과 |
|---|---|---|
| 철도역 | 16개 노선의 역·호선 조합 657개, 전국 철도 자료, 지도와 선로 형상 | 기존 4곳에 추가 4곳 보정 |
| 버스정류장 | 원자료 55,905개, 동일 NODE_ID로 비교 가능한 TOPIS 자료 6,249개 | 30m 이상 차이 28곳 중 1곳 보정 |
| 따릉이 | 모델 목록 2,789개, 현재 재고 응답의 대여소 2,713개 | 공통 번호 2,700개 중 위치 차이 209개, 이 중 30m 이상 104개 |

버스 원자료 수는 실제 탐색에 사용되는 서울 정류장 수가 아닙니다. 대여소 수는 위 확인일의 응답 기준입니다. 30m·250m 등 거리 기준은 검토 대상을 좁히는 작업 기준이며 오류 판정 기준이 아닙니다.

## 보정한 위치

- 기존 보정: 잠실새내 2호선, 신답 2호선, 용답 2호선, 발산 5호선.
- 추가 보정: 서울역 1호선, 마곡 5호선, 디지털미디어시티 6호선, 양원 경의중앙선.
- 버스: NODE_ID `122000716`, 서울 ARS `23390`. 기존 위치가 약 3.9km 어긋났습니다. TOPIS 좌표를 사용하고, 카카오·구글 지도에서 서울 정류장 번호와 6703번 노선을 확인했습니다. 카카오의 현재 명칭은 `경복아파트사거리.트레블로지강남역삼서울`, 구글·기존 자료에는 `글래드라이브강남호텔`로 남아 있습니다.

6703번은 별개로 원자료의 다른 정류장 30개 좌표가 없어 현재 시간표 탐색에서 제외되어 있습니다. 이번 위치 보정이 해당 노선을 복원한 것은 아닙니다.

보정 근거와 변경 전후 좌표는 `data/transit/files/subway_coordinate_corrections.json`, `bus_coordinate_corrections.json`에 있습니다. 시설 ID·이름·기존 좌표가 모두 맞을 때만 적용하므로, 나중에 원자료가 갱신되면 예전 보정으로 덮어쓰지 않습니다. 호선별 승강장은 하나로 합치지 않습니다.

양원은 전국 자료에도 서울 주소와 맞지 않는 먼 지역 좌표가 들어 있었습니다. 마곡의 전국 자료도 인근 발산 위치와 혼동되어 있었습니다. 이촌 4호선은 반대로 기존 위치가 선로와 맞아 전국 자료로 교체하지 않았습니다. **공식 자료나 여러 지도에 같은 값이 있다고 해서 곧바로 정확하다고 판단하지 않았습니다.**

## 따릉이 위치 사용

현재 재고 응답을 사용하는 경로 탐색에서는 정확히 매핑된 대여소 ID의 현재 위치를 도보 연결·자전거 OSM 경로·날씨 조회에 함께 사용합니다. 이동한 대여소에만 좌표를 예측 요청과 캐시 식별값에 포함합니다. 단순한 소수점 표현 차이는 이동으로 취급하지 않습니다.

모델의 과거 목록을 덮어쓰거나 학습을 다시 하지는 않습니다. 과거 스크린샷 기록처럼 현재 좌표를 지정하지 않은 요청은 기존 위치를 사용합니다. 실제 위치가 변하지 않은 대여소의 기존 예측 캐시도 검증된 환경에서 유지됩니다.

대여소 이전 날짜별 이력이 없으므로 과거 이용일의 실제 위치를 복원했다고 보장하지는 않습니다.

## 보류한 항목과 한계

- 나머지 버스 27곳은 이전·정차 위치·자료 시점 차이를 확인하지 못해 일괄 교체하지 않았습니다.
- 위치 차이 104개 대여소 중 카카오 검색에서 이름이 일치한 것은 10개였습니다. 나머지를 폐쇄·오류로 판정하지 않았습니다. 월계2교 대여소는 지도 화면에서 한천로의 시설 위치와 주소를 확인했습니다.
- 지도 회사도 같은 원자료를 쓸 수 있어, 좌표 일치 자체를 독립 검증으로 보지 않았습니다. ID, 지역, 주소, 노선·방향, 주변 도로·선로를 함께 확인했습니다.
- 네이버 일반 장소 검색의 접근 제한으로 모든 시설을 세 지도에서 대조하지 못했습니다. 네이버 역 정보, 카카오·구글 지도에서 확인 가능한 항목을 검토했습니다.
- 철도 좌표 중복 14그룹과 버스 좌표 중복 116그룹은 그대로 유지했습니다. 공동 승강장·정류장일 수 있어 중복 좌표만으로 분리하거나 삭제하지 않았습니다.
- 일부 철도역이 OSM 선로에서 멀게 잡힌 원인은 오래된 선로 형상의 누락일 수 있습니다. 해당 역을 가장 가까운 다른 선로로 옮기지 않았습니다.

거리 기준으로 선별한 미확정 항목의 좌표와 비교값은 [검토 목록](coordinate_review_20261030.json)에 남겼습니다. 전체 시설을 지도 화면에서 하나씩 실사한 결과는 아닙니다.

## 검증

기존 요청 30건의 모델 입력과 전체 예측 출력이 수정 전과 정확히 같았습니다. 현재 위치가 바뀐 `302 → 468`은 실제 OSM 경로를 다시 계산했고, 이어서 같은 OD의 과거 위치 요청이 원래 결과를 유지하는지 확인했습니다. 좌표가 바뀐 요청은 이전 위치의 예측 캐시와 구분됩니다.
