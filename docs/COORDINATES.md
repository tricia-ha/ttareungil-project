# 시설 좌표 반영

2026-11-01 기준입니다. 경로 탐색에는 카카오맵에서 확인한 역 위치와 따릉이 현재 대여소 응답을 우선합니다.

## 적용한 내용

| 대상 | 반영 내용 |
|---|---|
| 철도역 | 잠실새내·신답·용답 2호선, 마곡·발산 5호선, 디지털미디어시티 6호선, 서울역 1호선, 양원 경의중앙선의 좌표를 카카오맵 기준으로 보정 |
| 버스정류장 | 서울 ARS 23390과 24409의 잘못된 위치를 지도에서 같은 정류장 번호로 확인한 위치에 맞게 보정 |
| 따릉이 | 현재 응답 2,718개 중 모델 목록과 공통인 2,705개를 비교해 위치 변경 209개 반영. 이름 변경을 포함한 297개의 업데이트를 저장 |

따릉이 위치는 검토 목록에만 남기는 것이 아니라 **실제 경로 계산에 적용**합니다. 재고 조회를 끄면 저장된 현재 위치를 사용하고, 켜면 새로 받은 위치가 우선합니다. 도보 연결, 자전거 OSM 경로와 경로 특징, 날씨 조회가 같은 위치를 사용합니다.

실제 대여소 앱 화면을 2,718개 모두 확인한 것은 아닙니다. 따릉이 현재 정보는 [서울시 실시간 대여소 응답](https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do)에서 받았습니다.

## 파일과 갱신

- `data/inventory/station_location_updates.json`: 현재 대여소 위치·이름, 조회 시점, 모델 목록의 원래 좌표.
- `data/transit/files/subway_coordinate_corrections.json`, `bus_coordinate_corrections.json`: 지도에서 확인한 보정 위치와 근거.
- `src/station_coordinates.py`: 저장 위치 적용과 예측 요청의 좌표 연결.

모델 학습 당시 목록과 가중치는 덮어쓰지 않습니다. 현재 위치를 지정한 경로 탐색과 과거 이용내역 계산을 분리하며, 위치가 바뀐 요청의 예측 캐시도 이전 위치와 구분합니다. 원자료가 나중에 다른 위치로 갱신되면 저장된 예전 보정으로 덮어쓰지 않습니다.

## 동일 시설 확인

역 이름뿐 아니라 호선·주소를, 버스는 지역·정류장 번호·방향을, 따릉이는 대여소 번호를 확인합니다. 같은 이름의 다른 지역 시설이나 반대 방향 정류장을 대신 연결하지 않습니다. 일부 지도와 공공자료는 원천 자료를 공유하므로 단순히 좌표가 같다는 사실만으로 판정하지 않습니다.

교정한 역 8곳은 실제 일요일 시간표에도 반영되는 것을 확인했습니다. ARS 23390은 현재 지도에 `경복아파트사거리.트레블로지강남역삼서울`로 표시되며, 기존 자료의 `글래드라이브강남호텔`과 같은 정류장입니다. 다만 6703번은 다른 정류장 30개의 좌표가 원자료에 없어 현재 탐색에서 제외되어 있습니다.

## 검증 범위

기존 요청 30건의 모델 입력과 전체 예측 출력이 수정 전과 정확히 같았습니다. 이동한 대여소의 실제 OSM 경로가 바뀌고, 이후 과거 위치 요청은 원래 결과를 유지하는지도 확인했습니다. 대여소 이전 날짜별 이력은 없어 과거 이용일의 실제 위치를 복원한다고 보장하지는 않습니다.

지도에서 시설을 특정하지 못한 버스 좌표 차이나 선로 형상 누락은 별개이며, 전체 시설을 지도 화면에서 하나씩 실사한 결과는 아닙니다.
