# 검증 범위와 제한

## 자동 검사

Windows Python 3.13에서 전체 자동 검사를 수행합니다. 검사 결과는 실제 환경 전체의 정확도나 최단 경로 보장을 뜻하지 않습니다.

- 통합·버스/지하철·따릉이 모드와 환승·대기시간 처리
- 후보 유지, 왕복 경로 차단, A*·캐시·배치 계산의 결과 보존
- 추가 도보 API 오류·응답 지연 시 확보된 경로 보존과 대기시간 제한
- V5.2.1·재고·날씨 연결과 모델 파일 무결성
- 아이디 가입·로그인·비밀번호 변경·다른 기기 로그인 무효화
- OCR 카드 분리, 대여소 번호·이름 검증, 직접 수정·중복 등록 방지
- 개인화의 배율·고정 보정, 이전 기록만을 사용한 t 예측 상한
- HTTPS 쿠키·동일 출처·작업 소유권·비공개 파일 접근 차단
- 서로 다른 계정의 비밀번호·이력 분리, 공유 URL·프로필 쿠키만으로 로그인 불가
- 탐색 중 경로 전달·최단시간 순 정렬·다른 사용자 접근 차단·갱신 오류 후 경로 보존
- 새로고침 후 동일 작업·부분 결과·완료 결과와 입력 조건 복원, 빠른 중복 제출 방지
- 설치·상대 경로·필수 자료·개인 정보 포함 여부

검사 실행:

```powershell
.venv\Scripts\python.exe -B -m unittest discover -s tests
node tests/test_web_ux.js
node tests/test_route_resume.js
.venv\Scripts\python.exe -B scripts/check_project.py
.venv\Scripts\python.exe -B scripts/check_project_clean.py
```

Node.js 검사는 화면 로직을 위한 개발용 검사이며 서비스 실행에는 필요하지 않습니다.

## 실제 실행으로 확인한 범위

- 원본 이용내역 사진의 OCR·대여소 매핑·과거 날씨·기본 P50·개인화 연결
- 실제 시간표를 사용한 세 가지 탐색 모드와 버스·지하철 혼합 결과
- PC 웹과 휴대폰 크기 화면의 사진 자르기·확인·오류 복구
- ngrok 고정 HTTPS 주소, 인증서 검증, QR 연결과 서버 응답
- 한글·공백이 포함된 다른 폴더에서 모델 추론과 상대 경로 동작
- Python 3.11 Windows 의존성 해석과 현재 PC의 Python 3.13 실행

시간·호출 제한에 따른 `partial` 결과를 포함합니다. 동시 탐색 2건·대기 4건, 모델 중복 로드 방지, OCR 순차 처리, 자원 부족 시 대기와 종료, 동시 도보 조회의 캐시 공유·일일 호출 한도를 자동 검사합니다. 새 PC의 최초 설치 전체, 실제 휴대폰 기종별 조작, 대규모 동시 접속 성능은 검증하지 않았습니다.

## 데이터·모델의 제한

낙산공원→남산둘레길의 저장된 세 경로에 포함된 연결만 재현한 검사에서, 회현역↔대여소 왕복을 추가한 54분 52초·56분 30초 경로가 중복으로 정리되고 53분 14초 경로가 유지됐습니다. 전체 연결망의 새 경로 탐색 결과를 뜻하지는 않습니다. 왕복을 같은 시각의 대기로 대체하며 비정각 재고 기회, 도보 환승, 따릉이 재대여를 보존하는 별도 검사도 수행합니다.

2026-10-29 현재 PC의 저장된 시간표·도보 캐시로 같은 요청 2건을 비교했습니다. 탐색 제한은 각각 30초이며 자료 준비를 포함한 완료시간은 순차 97.19초, 동시 63.03초였습니다. 두 방식 모두 같은 경로 3개를 반환했고 외부 API 호출은 없었습니다. 실제 모델의 2개 OD에서도 계산 스레드 조정 전후 P50·P80·P90 차이는 0분이었습니다. 다른 요청·PC의 속도를 보장하는 수치는 아니며, 짧은 시간 제한이나 부하에 따라 탐색 결과는 달라질 수 있습니다.

- 버스는 첫차·막차·배차간격을 이용한 복원 시간표를 포함합니다. 실제 지연·운휴는 반영하지 않습니다.
- 일부 버스 정류장·철도 구간이 누락됩니다. 결과의 `data_gaps`를 확인합니다.
- 탐색은 설정한 거리·시간·호출 범위 안에서 진행됩니다. 경로 0개가 실제 경로 부재를 뜻하지 않을 수 있습니다.
- 대여소 목록은 포함된 자료의 기준 시점을 따릅니다. 목록에 없는 신규·과거 대여소는 자동 등록하지 않습니다.
- OCR은 화질·배치에 따라 실패할 수 있어 원본 확인이 필요합니다. 사진의 진위를 판별하지는 않습니다.
- 개인화의 실제 사용자 성능과 정상 이력 오제외율은 추가 검증 대상입니다. 합성 실험 결과를 실제 개선 효과로 해석하지 않습니다.
- 새 PC에서는 Python·패키지·인증키 권한과 외부 서비스 사용량을 별도로 확인해야 합니다.
