중계역 도착 후 노원역을 거쳐 다시 중계역으로 돌아오는 사례를 단순화하여 비교했습니다. 수정 전에는 8개 상태를 처리한 시점에 왕복 포함 50분 경로만 반환했고, 수정 후에는 같은 한도에서 따릉이·도보 36.7분 경로를 먼저 반환했습니다. 이 수치는 재현용 입력의 결과이며 실제 요청을 다시 호출한 결과는 아닙니다.

완성된 경로는 미완성 혼합 후보보다 먼저 반환하며, 혼합 후보가 있어도 보류된 도보 작업을 번갈아 처리합니다. 같은 역으로 돌아와도 이후 행동 조건이 같으면 왕복을 동일 시각의 대기로 대체합니다. 승강장 환승에 실제 차이가 있는 상태, 하차·승차 제한으로 차량에 머물러야 하는 경우, 자전거 재대여 가능 상태가 달라지는 경우는 유지합니다. 유효한 혼합 이동과 반복 대여를 검사하는 회귀 테스트를 포함했습니다. 탐색·호출 상한은 변경하지 않았습니다.
