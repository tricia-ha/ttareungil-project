# OSM 도보 연결과 카카오 보완

출발·도착 연결과 역·정류장·대여소 사이 지상 도보를 별도 보행 전용 OSM 그래프로 계산합니다. 기존 역 내부 환승자료는 유지합니다. 자전거 도로망을 보행망으로 재사용하지 않습니다.

## 적용 순서

1. 좌표와 방향이 일치하는 유효한 카카오 캐시가 있으면 그 시간·거리·경로를 우선합니다. 카카오의 경로 없음 응답도 유지합니다.
2. 완료된 OSM 타일 범위 안이면 도보망으로 계산하고 결과를 서버 DB에 저장합니다.
3. 범위 밖, 경로 없음, 스냅 거리 25m 초과, 큰 우회(직선거리 3배이면서 600m 초과)는 카카오로 확인합니다. 보행로가 명확하지 않은 큰 차도 중심선이나 자전거전용 길을 사용하는 연결도 길이와 무관하게 카카오로 확인합니다. 확인하지 못하면 OSM 추정값을 확정 연결로 채택하지 않습니다. 이 분류는 보수적인 확인 우선순위이며 실제 오류의 통계적 판정 기준이 아닙니다.
4. 카카오 호출이 불가능하면 직선 경로를 만들어 넣지 않습니다. 기존에 확인된 후보는 유지합니다.

OSM 도보는 기본 초속 1.2m, 계단은 초속 0.8m로 계산한 추정입니다. 신호 대기나 실제 출입구·운영시간을 모두 반영하지 못합니다. 카카오와 차이가 있어도 전 지역의 시간을 임의의 배율로 바꾸지 않고 해당 좌표·방향의 확인값을 우선합니다. 정확한 같은 구간을 다음에 검색하면 보완된 값으로 처음부터 시간표를 계산합니다. 이미 완성된 시간표 경로의 도보시간만 뒤늦게 바꾸지 않습니다.

기존 적응형 후보 순서와 최대 2.4km 도보 후보 범위를 사용합니다. 고정된 가까운 몇 곳만 남기는 방식으로 줄이지 않습니다. 연결은 필요할 때 불러오므로 수십만 개의 환승 연결을 전부 검색 객체로 올리지 않습니다. 그래프는 프로세스에서 공유하고, 출발 도로 노드별 계산 결과는 최대 16개를 메모리에 유지합니다.

## 자료 구축

추가 반복 실험으로 선택한 `complex_walk` 조건(60도 초과 방향 변화가 6회 이상인 도보)도 카카오 확인 대상으로 분류합니다. 조건은 `data/walking/verification_policy.json`에서 읽으며, 이미 저장한 OSM 값을 사용할 때도 매번 다시 확인합니다. [3회 반복 비교 결과](WALKING_ITERATIONS.md)를 참고합니다.

프로젝트 폴더에서 실행합니다.

```powershell
python scripts/build_osm_walking.py --max-tiles 12
```

성공한 타일과 원본 응답을 저장합니다. 중단 후 같은 명령으로 재개합니다. HTTP 오류가 난 타일은 완료 처리하지 않으며 다른 타일을 계속 진행합니다. 웹 검색 중에는 자동 다운로드하지 않습니다. 도보망이 없으면 기존 카카오 경로로 동작합니다. 원본을 다시 받지 않고 필터를 새로 적용할 때는 `python scripts/build_osm_walking.py --rebuild-cached`를 실행합니다. 버스전용 차로와 보행금지 도로는 계산망에서 제외합니다.

자료: `data/walking/seoul_walk.sqlite`
원본 체크포인트: `data/walking/tiles/`
검색 중 계산한 도보: `cache/runtime/osm_walks.sqlite` (기존 private 폴더 설정 사용)

SQLite 파일은 기본 Git 제외 대상입니다. 폴더를 압축해 실행환경을 전달할 때 도보 DB를 포함하거나, 새 환경에서 구축 명령을 실행해야 합니다. 원본 타일은 재구축용이며 실행에 필수는 아닙니다. 새 자료 구축 후 서버를 재시작합니다.

## 무작위 비교

```powershell
python scripts/audit_osm_walking.py --count 12 --max-calls 12
```

기본 난수는 20261102입니다. 완료된 자료 범위의 직선거리 30~600m 후보에서 지하철↔버스, 지하철↔따릉이, 버스↔따릉이, 버스↔버스를 각각 3개씩 선정합니다. 경로 계산 성공 여부를 알기 전에 표본을 고르고 실패도 보고서에 남깁니다. 역 내부 환승은 이 표본에 포함하지 않습니다.

보고서: `outputs/runtime/diagnostics/osm_kakao_walk_comparison.json`
새 카카오 호출 상한: 기본 12회, 일일 1,000회 안에서 차감. 기존 캐시가 있으면 재사용합니다.
차이 확인 표시: 절대차 2분 이상이면서 비율 1.5배 이상 또는 그 역수 이하. 소량 표본의 기술통계이며 전체 지역 정확도의 증명은 아닙니다.

공식 구조 참고: https://osmnx.readthedocs.io/en/stable/user-reference.html (보행망과 자전거망 구분). 자료 출처: OpenStreetMap contributors / Overpass.
