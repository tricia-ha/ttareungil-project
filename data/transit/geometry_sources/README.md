# 지도 표시용 노선 형상

버스는 서울 교통 빅데이터 플랫폼의 공간 링크(63), 노선 링크(57), 노선별 경유노드(58), 링크정보(52)를 연결합니다. 대괄호 숫자는 데이터 ID입니다. 수집일: 2026-10-17.

정류장 순번과 노선 ID로 도로 링크를 선택하고 정류장 위치에 맞춰 형상을 잘라냅니다. 원자료의 40m 초과 단절은 직선으로 메우지 않고 분리해 표시합니다.

지하철은 `rail_lines/`의 공개 OSM 선로 GeoJSON을 사용합니다. [원본 내보내기 저장소](https://github.com/jebowe3/seoul_transportation)의 고정 커밋, 파일별 해시와 출처를 `rail_lines/sources.json`에 기록합니다. 1~9호선과 추가 7개 노선의 선로 형상이 포함됩니다. 지도 선로를 따라 같은 노선 안에서만 연결하며, 끊어진 선로 사이에 임의의 연결을 만들지 않습니다. 자료의 원래 측량·갱신일은 확인되지 않아 현재 운영 선로와 완전히 같다고 보장하지 않습니다.

실제 도로·선로 좌표는 `geometry`, 자료가 없는 구간의 개략 연결은 `display_geometry`로 구분합니다. 환승은 보라색 점선, 형상 미확보 구간은 주황색 점선으로 표시하며 실제 실내 통로나 실제 도로로 해석하면 안 됩니다. 공개 형상 재수집은 `python scripts/download_rail_shapes.py`로 하며 기존 파일은 건너뜁니다.

형상 처리는 검색 이후에만 적용됩니다. 이동시간, 대기시간, 예측값, 경로 순위에는 영향을 주지 않습니다. 따릉이 형상은 기존 OSM 경로, 도보 형상은 기존 카카오 도보 경로를 유지합니다.

`python scripts/refresh_route_map.py`는 저장된 결과의 지도만 갱신하며 모델이나 인증 API를 호출하지 않습니다.
