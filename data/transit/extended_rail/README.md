# 수도권 추가 철도 시간표

`02_시간표최적화.ipynb`의 Run All에서 자동으로 연결합니다. 다운로드는 완료되어 있으며 시간표 준비에 인증키나 네트워크는 필요하지 않습니다. 기존 커널을 사용 중이라면 커널을 재시작해 수정된 모듈을 읽으십시오.

| 노선 | 원자료 | 시간표 처리 |
|---|---|---|
| 경의중앙선·경춘선 | 코레일 2026-09-01 시행 XLSX | 평일/휴일, 열차번호, 도착·출발시각 유지. 경의선 서울역 지선 포함. ITX-청춘 제외 |
| 수인분당선 | 코레일 2026-08-22 시행 XLSX | 평일/휴일, 열차번호, 도착·출발시각 유지 |
| 공항철도 | 운영사 2025-12-29 및 2026-10-23 시행 XLSX | 날짜에 맞는 개정판 선택. 일반열차만 사용 |
| 신분당선 | 운영사 역별 시간표 | 평일/주말·공휴일 분 단위 출발시간으로 열차 연결 추정. 정자행 구분 |
| 우이신설선·신림선 | 운영사 역별 시간표 | 평일/주말·공휴일 분 단위 출발시간으로 열차 연결 추정 |

## 한계

- 역별 출발시간만 있는 3개 노선은 운영사가 열차번호를 제공하지 않아 같은 열차의 연결을 확정할 수 없습니다. 시간순서·진행방향·종착역 및 물리적 속도 하한 조건으로 연결하며, 결과의 `timetable_method`에 추정임을 보존합니다.
- 이 3개 노선의 양 끝 종착역은 도착시각을 제공하지 않습니다. 따라서 종착역 직전에서 종착역으로 들어가는 구간은 생성하지 않습니다. 전체 노선의 모든 구간이 완성됐다는 뜻은 아닙니다.
- 환승역 내부 연결은 동일 역명과 좌표 거리로 확인하며 이동시간은 추정값입니다. 출입구·플랫폼별 실제 환승시간 데이터는 아닙니다.
- 실제 선로 형상은 `geometry_sources/rail_lines/`의 OSM 내보내기 자료를 사용합니다. 실제 선로를 연결할 수 없는 구간은 개략도 점선으로 구분하며 운행시간 추정에는 사용하지 않습니다.
- 수도권의 다른 노선(서해선·경강선·인천선·GTX 등)은 이번 추가 대상이 아닙니다.

## 파일

- `sources.json`: 파일별 공식 주소·용량·SHA256
- `normalized.csv`: 검색용으로 정규화한 열차별 역 이벤트
- `manifest.json`: 좌표 매칭, 변환 방식, 노선별 행 수, 누락
- `coverage_report.json`: 평일·토요일·일요일·공항철도 개정 후의 생성 구간 검증

원자료 재수집: `python scripts/download_extended_rail_sources.py`. 이미 있는 파일은 건너뛰며 새 개정판 적용은 다운로드 주소와 시행일을 함께 갱신해야 합니다.
